# Before posting to arXiv
1. Independent expert reading of the paper against the code (not done).
2. Put this directory in a public repository (GitHub + Zenodo DOI) and insert the URL in paper/arxiv_abstract.txt and §7 of the paper.
3. Replace `logs_reference/` with the logs of a clean run on a second machine.
4. arXiv endorsement: first-time submitters to math.NT generally need an endorser (https://arxiv.org/help/endorsement).
5. Re-search the literature for results on the cubic Borwein conjecture posted after Sept 2026.
